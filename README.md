## Reproducing All Results

### Requirements

```
python >= 3.10
numpy
scipy
matplotlib
torch  (for neural attacker baselines: KPA-MLP, KPA-LSTM, KPA-TX, KPA-HYB)
```

Install dependencies:
```bash
pip install numpy scipy matplotlib torch
```

### Run the full publication suite

```bash
python run.py
```

This regenerates all figures and CSV files into a local `mcf_pls_figs3/` directory,
then mirrors the generated CSV artifacts into `data/` and the generated PNG
artifacts into `figures/` so the repository's article assets stay aligned with
the publication runner.
Runtime is approximately 2–4 hours on a standard CPU (the 37-core multi-seed run dominates).

All random seeds are fixed (default seed = 42; multi-seed suite uses seeds 42–46)
so results are fully reproducible.

The original monolithic script is also kept for reference:
```bash
python mcf_pls_sim_v3.py   # identical output, single-file version
```

## Reproducibility Manifest

`data/reproducibility_manifest.csv` maps every figure and table in the paper to its
source CSV file in `data/`. Each CSV was generated by a named function in
`mcf_pls_sim_v3.py` — the manifest links function names, output files, and figure numbers.

`data/publication_suite_config.csv` records the exact simulation parameters, key,
and tap configuration used for the main benchmark.

`data/physical_parameter_traceability.csv` classifies every physical parameter as
**Public** (from published literature), **Model** (computed from waveguide theory),
or **Design** (operating-point choice).

| Parameter | Value | Source |
|-----------|-------|--------|
| Core diameter | 8.2 μm | Cohen et al. (2016) |
| Pitch | 16.4 μm | Cohen et al. (2016) |

## Attack Models

Six attacker baselines are benchmarked under FO (full-observation) and WT (wiretap) threat models:

| Attacker | Type | Description |
|----------|------|-------------|
| KPA-CE | Closed-form | OLS channel estimation + MMSE equalization |
| KPA-LR | Closed-form | Direct OLS regression (y → x) |
| KPA-MLP | Neural | 3-layer feed-forward MLP with GELU |
| KPA-LSTM | Neural | 2-layer LSTM with sliding window |
| KPA-TX | Neural | Transformer encoder (2 layers, 4 heads) |
| KPA-HYB | Neural | LR linear estimate + residual MLP correction |
